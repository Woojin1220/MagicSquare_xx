# PRD — MagicSquare_xx (4×4 부분 마방진)

## 1. 배경 (Mom Test)

4×4 부분 마방진(빈칸 2개, **10선 합 34**) 과제에서 학습자가 **특정 행·열부터** 합을 맞추고, 대각선 `\`·`/`까지 본 뒤 **맞다고 생각하고 제출**했으나 **채점 결과**에서 오답이었다. 처음부터 다시 하며 **반대 대각선 `/` 합**이 틀렸음을 알게 되었고, 그 문제에 **약 10분**을 추가로 썼다(Mom Test).

본 PRD의 1차 목표는 **"10선=34 판정을 빠짐없이·기계적으로 수행하고, 깨진 줄(특히 `/`)을 즉시 식별"** 하는 것이다.

### Mom Test 요약

| 항목 | 내용 |
|------|------|
| **페르소나** | 4×4 부분 마방진을 손으로/코드로 다루는 학습자 |
| **진짜 문제** | 손 검증·`/`` 34 비교 후에도 채점 오답 → 재풀이 중 `/` 합 오류 발견 · **10분** 추가 |
| **증거** | 「행·열부터 맞춤」 / 「맞다고 넘어감」 / 「채점→10분→반대 대각선」 |
| **표면 문제 (비목표)** | 「검증/풀이 프로그램·PyQt 완성 앱·ECB 설계 완성」만을 목표로 삼기 |
| **미확인** | `/` 검증 시 빈칸 2칸에 최종 숫자가 들어가 있었는지 (인터뷰 Q11) |

## 2. 목표

- 4×4 격자(빈칸 **정확히 2개**)에 대해 **10선** 합이 **34**인지 검증한다.
- 실패 시 **어느 줄**(행 / 열 / `\` / `/`)이 깨졌는지 식별한다.
- 빈칸 좌표 탐색 및 후보 값에 대한 판정을 제공한다(Logic Track).
- 제출·채점 **전에** SC-1~3을 만족하는 판정 경로를 확보한다(채점 후 10분 재작업 방지).

## 3. 비목표

- 완성된 PyQt 상용 앱 · 배포
- 3×3 / 5×5 / 마방진 자동 생성 · 난이도 확장
- 세션 3에서 Domain GREEN · UI 구현 **완료**
- “대충 맞는 것 같다” 수동 확인만으로 완료 처리

## 4. 사용자

- **Primary:** 4×4 부분 마방진 과제를 받은 프로그래밍 수업 학습자
- **Secondary:** TDD / ECB / Cursor 워크플로 실습자

## 5. 도메인 규칙

| 규칙 | 설명 |
|------|------|
| R-01 | 격자는 **4×4** |
| R-02 | 셀 값: `0`(빈칸) 또는 `1..16` |
| R-03 | 빈칸(`0`)은 **정확히 2개** |
| R-04 | 1~16은 **중복 없음** (0 제외) |
| R-05 | **10선** 각각의 합 = **34** |
| R-06 | 10선 = 행 4 + 열 4 + 주대각선 `\` + 반대 대각선 `/` |

### 예시 격자 (슬라이드 4.1)

| | c1 | c2 | c3 | c4 |
|---|----|----|----|-----|
| r1 | 16 | 3 | 2 | 13 |
| r2 | 5 | 10 | 11 | **0** |
| r3 | 9 | 6 | **0** | 12 |
| r4 | 4 | 15 | 14 | 1 |

빈칸 좌표: (r2,c4), (r3,c3). 마법 상수 **34**.
